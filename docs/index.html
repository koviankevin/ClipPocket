A FEW THINGS TO KNOW

開始前，你可能想知道。

回報問題 ↗
這個網頁可以直接貼影片網址下載嗎？＋

請先從這個頁面下載免安裝工具，再在自己的電腦開啟 ClipPocket.exe。這裡提供下載與教學；貼影片網址的操作畫面，會由本機工具另外開啟。

Windows 說「未知發行者」，是什麼意思？＋

目前版本尚未做程式碼簽章，因此 Windows 可能顯示未知發行者。請確認下載來源是本專案的 GitHub Release，再依自己的安全判斷決定是否執行。原始碼、隨附元件與校驗碼都公開提供。

手機或 Mac 也可以用嗎？＋

目前提供 Windows 64 位元版，適用 Windows 10 22H2／Windows 11。手機、macOS、Linux 及 Windows ARM 目前未提供對應下載包。

所有影片、所有畫質都能下載嗎？＋

目前支援 YouTube、Facebook、Bilibili 的公開、免登入、非直播單支影片，不讀取帳號 Cookie。影片下架、地區或帳號限制，以及平台改版，都可能影響下載。

畫質選單依來源實際可取得的格式提供，不會放大影片；Bilibili 部分高畫質可能需要帳號權限。4K60 已實測三秒片段，完整 8K 媒體尚未實測。

成品存在哪裡？為什麼工具還有暫存？＋

瀏覽器模式的存檔位置，請從瀏覽器下載清單查看。工具會保留處理好的暫存，方便再次儲存；暫存與瀏覽器存出的成品，會短暫占用兩份空間。

請等瀏覽器完成儲存再關閉工具。關閉工具會清除此次暫存，已存好的成品不受影響。如果只關閉分頁，工具在沒有工作或檔案傳送時，閒置約三分鐘會退出。

下載失敗，或按了之後沒反應？＋

先確認已完整解壓縮，並透過 ClipPocket.exe 開啟工具。若影片無法下載，可在工具內展開「查看處理紀錄」，或換一支公開、免登入的影片測試。

如果影片已處理好，但瀏覽器未自動儲存，按「再次儲存到瀏覽器」重試。仍有問題，可到 GitHub Issues 提供版本、平台與錯誤訊息；請勿貼上 Cookie、權杖或私人資料。
