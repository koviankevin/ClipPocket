ClipPocket v0.4.1 — 影片帶著走（Windows 免安裝版）

開始使用
1. 先把 ZIP 完整解壓縮到一個資料夾。
2. 雙擊 ClipPocket.exe，瀏覽器會開啟工具畫面。
3. 貼上 YouTube、Facebook 或 Bilibili 的單支公開影片網址。
4. 按「讀取資訊」，選實際可用畫質，再選 MP4 或 MP3。
5. 預設按「處理並交給瀏覽器儲存」，完成影音處理後會自動啟動瀏覽器下載。

升級時請先在舊版畫面按「關閉工具」，再解壓並開啟新版。

不需要安裝 Python、Node、FFmpeg，也不需要管理員權限。
請保留整個資料夾；只有 ClipPocket.exe 單獨一個檔案不能運作。
這個驗證版尚未簽章，Windows 可能顯示未知發行者。

檔案在哪裡？
預設「透過瀏覽器下載管理員」：儲存位置、同名處理及是否詢問另存位置，依你自己的瀏覽器設定。
網頁顯示取得影片與合併／轉檔進度；最後接收成品的進度，請在瀏覽器下載清單查看。
如果瀏覽器沒有自動開始下載，請在「最近處理」按「再次儲存到瀏覽器」。
這個按鈕直接重用處理好的檔案，不會重新抓取來源影片。
網頁無法確認瀏覽器是否真的完成儲存，也無法知道瀏覽器最後選的資料夾。

也可在「儲存方式」改選「直接存到指定資料夾」。
此模式預設使用工具資料夾內的 Downloads，可以按「變更」選擇其他資料夾。
直接儲存同名檔案會加上數字，不會覆蓋原檔；「在資料夾中顯示」及「開啟資料夾」可查看成品。

瀏覽器模式暫存
成品會暫存在工具的 data/browser-downloads 資料夾；交給瀏覽器時採串流傳送，不把整支影片載入網頁記憶體。
暫存可保留到關閉工具，方便瀏覽器重試或部分內容續傳；實際自動續傳仍依瀏覽器行為。
請等瀏覽器完成儲存再關閉工具。關閉工具會清除此次瀏覽器暫存，已存好的檔案不受影響。
重新開啟工具時會清理已結束程序遺留的瀏覽器暫存，不清除其他仍在運行的工具暫存。
瀏覽器存出的成品與工具暫存會短暫占用兩份空間。

使用範圍
- YouTube、Facebook、Bilibili：以實際測試紀錄為準；不保證每支影片都可用。
- 畫質選項會依影片列出實際解析度與幀率，包括來源提供的 144p、240p、360p、480p、720p、1080p、1440p、2160p（4K）等，不再限制 1080p，也不會放大原片。
- 「最佳可用畫質」選最高可取得解析度，再選該解析度的最高幀率。
- 「相容模式」必要時轉為 H.264＋AAC，保留所選尺寸與幀率；高畫質轉檔較久。
- 「保留來源編碼」只合併／封裝，通常較快且避免重新編碼；部分播放器可能無法播放來源的 AV1／VP9。
- MP3：192 kbps；只有聲音，不含畫面。
- Bilibili MP4 和 MP3 已實測通過；只顯示目前免登入可取得的畫質。其他畫質可能需要平台帳號權限，此版不讀取 Cookie。
- 第一版處理公開、免登入、非直播的單支影片，不讀取帳號 Cookie。

關閉與隱私
下載工作在使用者自己的電腦執行，不經我們的下載伺服器。
工具只監聽本機 127.0.0.1，不對家中其他裝置開放。
用完按畫面右上方「關閉工具」。若只關分頁，閒置約三分鐘且沒有工作時會退出。
直接儲存的紀錄與選擇的資料夾保存在工具的 data 資料夾；瀏覽器暫存紀錄只保留在此次執行期間。
不會新增開機啟動項目或 Windows 背景服務。

如果失敗
先按「查看處理紀錄」。影片可能已下架、要求登入、受地區限制，或平台已改版。
工具不會自動讀取瀏覽器的登入資訊。
若畫面沒有開啟，可查看 data/startup-error.txt。
此版本適用 Windows 10／11 64 位元；其他系統尚未打包驗證。

「開啟資料夾」及「在資料夾中顯示」已修正成顯示可見的檔案總管視窗，操作成功也會顯示提示。

元件版本、官方來源與授權文件見 THIRD_PARTY.md 和 licenses 資料夾。

自動檢查與一鍵更新（v0.4.0 起）
工具啟動時及開啟期間每六小時檢查 GitHub 正式版本；也可按「檢查更新」。不需要帳號或固定月費，關閉工具後不會在背景執行。
有新版時，先確認影片已在瀏覽器下載清單儲存完成，再按「一鍵更新」。工具會下載並校驗更新包，自動解壓、替換程式及重開。更新會清除這次執行的瀏覽器暫存，保留 data 設定、歷史、Downloads 與其他資料夾的成品。
程式只接受本專案 GitHub 正式 Release 的 Windows x64 ZIP，核對 GitHub 提供的 SHA-256，再核對包內清單。沒有網路或檢查失敗時，仍可照常使用。
更新失敗會嘗試還原舊版並重開。請勿在更新時強制關機、拔除隨身碟或手動搬移工具；若還原也失敗，畫面會顯示保留的備份位置，紀錄在 data/update-result.json。需要足夠的磁碟空間存放更新包、解壓檔及備份。
v0.3.0 或更舊版本需先手動下載、解壓新版一次；之後即可使用一鍵更新。

可讀性與關閉（v0.4.1）
主要按鈕、輸入欄與選項至少 16px，說明文字至少 14px。按「關閉工具」後會顯示整頁關閉完成提示；瀏覽器分頁仍可自行關閉（Ctrl＋W），本機程式已停止，不需一直開著。
